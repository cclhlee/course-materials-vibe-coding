# 除錯挑戰：找出條件判斷的邏輯與語法錯誤

> 第3週：變數、資料型態與條件判斷 — 對應簡報「除錯挑戰：找出條件判斷的邏輯與語法錯誤」段落，實作時段：120-140分鐘

## 學習目標

在不依賴AI直接修好的情況下，練習自行閱讀程式碼、比對測試資料，找出常見的條件判斷錯誤類型（變數名稱大小寫、比較運算子用錯、忘記括號）。

## 操作步驟

1. 兩兩一組，先不要執行程式碼，直接閱讀下方「錯誤版本」，寫下你們認為有問題的行數與原因。
2. 討論完成後，將程式碼貼到Replit中執行，觀察錯誤訊息或錯誤的輸出結果，確認你們的判斷是否正確。
3. 對照「測試資料」表格，找出哪一組測試資料會讓錯誤版本產生錯誤的輸出。
4. 合作修正程式碼，使其能正確處理所有測試資料，並與下方「修正版本」核對。
5. 換手：修正過程中請兩人輪流打字與口頭複述目前發現的問題，確保雙方都能解釋每一個修正點。

## 提示（卡關時再看，上課前請勿提前公布）

- 第1行宣告的變數是 Bmi（大寫B），但第3行判斷用的是 bmi（小寫b）——JavaScript對大小寫敏感，這會直接拋出 ReferenceError。
- 第5行 else if (bmi < 24 { 少了一個右括號 )，語法錯誤會讓程式完全無法執行。
- 修正大小寫與括號問題後，再用bmi=24驗證：24不小於24，所以會跳到下一個條件（bmi<27成立），歸類為「過重」，這是正確答案。
