# 用藥劑量依年齡分級判斷

> 第3週：變數、資料型態與條件判斷 — 對應簡報「用藥劑量依年齡分級判斷」段落，實作時段：75-120分鐘

## 學習目標

練習寫出能讓AI生成正確條件判斷邏輯的提示，並用手寫追蹤（trace）驗證AI生成的程式碼是否符合三個年齡分級的預期輸出。

## 操作步驟

1. 兩兩一組，先在紙上用自然語言寫下「兒童／成人／老年人」三個年齡分級與對應劑量的判斷規則（不要先看程式碼）。
2. 把規則轉成提示文字，貼到Replit的AI對話框，請AI生成JavaScript程式碼。
3. 對照下方「測試資料」表格，手寫追蹤每一組輸入資料在AI生成程式碼中會執行到哪一個條件分支，預測輸出結果。
4. 實際執行程式碼，比對實際輸出與手寫預測是否一致；若不一致，兩人討論是規則寫得不夠精準，還是AI生成的程式碼有誤。
5. 找助教或鄰組同學，口頭解釋自己程式碼中每一行的作用，特別是為什麼條件判斷的順序是先判斷兒童、再判斷成人、最後才是老年人。

## 給AI的提示詞範例（starterPrompt）

> 請用JavaScript寫一個函式，輸入病患年齡（age，單位：歲），依照以下規則印出建議劑量：年齡小於12歲屬於兒童，顯示「兒童劑量：5毫克」；年齡12歲以上且小於65歲屬於成人，顯示「成人劑量：10毫克」；年齡65歲以上屬於老年人，顯示「老年人劑量：7毫克」。請用if/else if/else實作，並在最後印出結果。

## 測試資料

| 輸入 age | 應歸類為 | 預期輸出 |
| --- | --- | --- |
| 5 | 兒童 | 兒童劑量：5毫克 |
| 11 | 兒童 | 兒童劑量：5毫克 |
| 12 | 成人（邊界值） | 成人劑量：10毫克 |
| 30 | 成人 | 成人劑量：10毫克 |
| 64 | 成人（邊界值） | 成人劑量：10毫克 |
| 65 | 老年人（邊界值） | 老年人劑量：7毫克 |
| 80 | 老年人 | 老年人劑量：7毫克 |

## 提示（卡關時再看，上課前請勿提前公布）

- 先確認12歲與65歲這兩個「邊界值」分別歸類到哪一組——這是最容易寫錯的地方。
- 如果AI生成的程式碼用 age <= 12 而不是 age < 12，測試資料中的12歲會被誤判為兒童，請對照測試資料表格檢查。
- if/else if/else 的判斷是「由上往下、找到第一個成立的條件就停止」，所以順序很重要：如果把「老年人」判斷放在最前面，且條件寫成 age > 0，所有人都會被誤判為老年人。
