# 健康量表分數加總與平均計算

> 第4週：迴圈、函式與除錯基礎 — 對應簡報「健康量表分數加總與平均計算」段落，實作時段：75-110分鐘

## 學習目標

練習寫出能讓AI生成迴圈搭配函式的提示，並用手寫追蹤驗證AI生成的程式碼是否正確計算加總與平均分數。

## 操作步驟

1. 兩兩一組，先在紙上寫下「輸入一組分數，計算總分與平均分數」的步驟（先用迴圈逐一加總，再除以總筆數）。
2. 把步驟轉成提示文字，貼到Replit的AI對話框，請AI生成JavaScript函式。
3. 對照下方「測試資料」表格，手寫追蹤迴圈每一次執行後total的值，預測最終總分與平均分數。
4. 實際執行程式碼，比對實際輸出與手寫預測是否一致；若不一致，檢查是迴圈邊界寫錯，還是平均計算公式有誤。
5. 找鄰組同學，口頭解釋自己程式碼中函式如何把迴圈邏輯封裝起來，為什麼要把計算邏輯獨立成函式而不是寫在最外層。

## 給AI的提示詞範例（starterPrompt）

> 請用JavaScript寫一個函式calcScores，輸入一個健康量表分數陣列（scores），使用for迴圈計算所有分數的加總，再計算平均分數（取到小數點後1位），最後印出「總分：X，平均分數：Y」，並讓函式回傳一個包含total與average的物件。

## 測試資料

| 輸入 scores | 預期總分 | 預期平均分數 |
| --- | --- | --- |
| [8, 6, 9, 7, 10] | 40 | 8.0 |
| [5, 5, 5, 5] | 20 | 5.0 |
| [10, 10, 10, 10, 10, 10] | 60 | 10.0 |
| [3, 4] | 7 | 3.5（邊界：僅2筆資料） |

## 提示（卡關時再看，上課前請勿提前公布）

- 迴圈開始前一定要先宣告 let total = 0，否則第一次執行 total += scores[i] 時會找不到total。
- 迴圈條件要用 i < scores.length（不是 <=），否則會多存取一個不存在的位置，導致平均分數變成NaN。
- toFixed(1) 是把數字格式化成字串並保留小數點後1位，如果後面還要拿average做其他數學運算，記得toFixed的回傳值是字串，不是數字。

## 討論問題

- 為什麼要把「加總」與「平均」這兩個計算都放進同一個函式，而不是拆成兩個更小的函式？兩種寫法各有什麼優缺點？
- 如果測試資料的陣列是空陣列 []，你預期calcScores會輸出什麼？實際執行後跟預測一致嗎？為什麼？
- 這個函式回傳的是一個物件 { total, average }，而不是只印出結果，這樣設計對後續要把分數存進資料庫（第7週會學到）有什麼幫助？
