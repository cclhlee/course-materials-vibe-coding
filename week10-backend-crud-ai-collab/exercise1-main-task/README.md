# 動手實作1：以增量式Prompt完成用藥時程的Create+Read功能

> 第10週：後端開發：AI協作實作CRUD功能 — 對應簡報「動手實作1：以增量式Prompt完成用藥時程的Create+Read功能」段落，實作時段：75-120分鐘

## 學習目標

練習用自然語言逐步prompt生成CRUD功能（至少Create+Read兩項），並在每完成一項後寫下「三句話說明」，訓練主動理解AI生成程式碼的習慣。

## 操作步驟

1. 延續第9週定稿的「使用者／用藥時程／服藥紀錄」schema（或自訂schema），在Replit中開啟Database工具，確認資料庫已建立且三張表都存在。
2. 第一步：只請AI生成「新增一筆用藥時程」的Create功能（INSERT語句＋對應的程式碼），先不要要求任何其他功能。
3. 執行並測試Create功能：在Database工具面板中確認新資料真的被寫入，接著寫下這個功能的「三句話說明」（做什麼、為什麼這樣寫、風險是什麼）。
4. 第二步：驗證Create功能沒問題後，才請AI加上「依使用者ID查詢用藥時程」的Read功能，同樣執行測試並寫下三句話說明。
5. （進階，若時間允許）依相同流程，逐步加上Update與Delete功能，每一步都先驗證再前進，並持續記錄三句話說明。
6. 兩兩一組互相口頭複述對方寫的三句話說明，確認彼此都真正理解程式碼在做什麼，而不是只有其中一人理解。

## 給AI的提示詞範例（starterPrompt）

> 請幫我針對「用藥時程」資料表（欄位：時程ID主鍵、使用者ID外鍵、藥名、劑量、服用時間、頻率）寫一個Node.js函式，使用參數化查詢，把新增用藥時程的INSERT語句包裝成一個函式，先不要幫我做查詢、修改或刪除功能。

## 測試資料

## 提示（卡關時再看，上課前請勿提前公布）

- 先確認自己能對Create功能講出三句話說明，再開口請AI加下一個功能，這是本練習最重要的紀律。
- 測試Create功能時，可以直接在Replit的Database工具面板中查看資料表內容，用視覺化的方式確認資料真的被寫入，不要只看程式有沒有報錯。
- 如果AI一次生成的程式碼中出現你看不懂的語法（例如RETURNING子句），應該先請AI用白話解釋這行的作用，再決定是否採用，而不是直接跳過。
