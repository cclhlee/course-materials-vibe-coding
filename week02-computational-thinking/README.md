# 第2週：運算思維與問題拆解

本週評量項目為「流程圖作業」——核心邏輯須由學生本人手繪／繪製，禁止使用AI生成流程圖本體。因此本週沒有程式碼練習檔或SQL匯入檔，僅提供作業最佳範例供教師課堂展示。

## 內容

- `homework-best-example/第2週作業最佳範例_用藥提醒系統流程圖.docx` — 完整作業範例（情境假設、流程圖、符號對照表、自我檢查清單、與課堂案例的差異說明）
- `homework-best-example/medication_reminder_flowchart.png` — 流程圖圖檔（用藥提醒系統，每日三時段迴圈檢查）
- `homework-best-example/medication_reminder_flowchart.dot` — Graphviz原始碼，教師可自行修改後以 `dot -Tpng -Gdpi=150 medication_reminder_flowchart.dot -o output.png` 重新產生
