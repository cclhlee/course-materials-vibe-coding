# 練習2：用AI檢查資安風險並分類ZAP掃描摘要

> 第12週：前後端整合、使用者驗證與資安基礎 — 對應簡報「練習2：用AI檢查資安風險並分類ZAP掃描摘要」段落，實作時段：135-145分鐘

## 學習目標

讓學生練習把「請AI檢查這段程式碼有沒有資安風險」作為固定除錯步驟，並能分辨掃描報告中「資訊性提示」與「高風險項目」的差異

## 操作步驟

1. 閱讀教師提供的codeBuggy程式碼片段（含SQL Injection風險的字串拼接查詢與缺少輸入驗證的表單處理）
2. 對AI輸入prompt：「請檢查這段程式碼有沒有資安風險」，記錄AI指出的問題
3. 根據AI的建議修正程式碼（對應codeGood），並口頭說明修正前後的差異
4. 閱讀教師提供的模擬ZAP掃描摘要列表（10項左右，混合FAIL/WARN/PASS等級與不同規則），將每一項分類為「需要立即修補的高風險項目」或「可暫緩的資訊性提示」，並寫下分類理由

## 給AI的提示詞範例（starterPrompt）

> 請檢查這段程式碼有沒有資安風險，並說明如果有問題應該怎麼修正：
[貼上下方codeBuggy程式碼]

## 測試資料

| 測試情境 | 預期結果 |
| --- | --- |
| userId=1（正常輸入） | 正常回傳該使用者的用藥時程 |
| userId="1' OR '1'='1"（SQL Injection測試） | codeBuggy版本會回傳所有人的資料（弱點重現）；codeGood版本會被拒絕（400錯誤） |

## 提示（卡關時再看，上課前請勿提前公布）

- 提示AI時可以具體一點，例如『這段程式碼有沒有SQL Injection風險』會得到更精準的回答，但也要練習用開放式問題「有沒有資安風險」來訓練自己判斷AI回答的完整性
- 分類ZAP摘要時可以參考本週表格：critical/high類問題傾向立即處理，info/低風險WARN可先記錄

- 有沒有AI講的但你認為不需要馬上處理的？為什麼？
