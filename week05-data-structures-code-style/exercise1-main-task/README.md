# 物件陣列動手實作：病患用藥清單資料結構設計

> 第5週：資料結構與程式風格規範 — 對應簡報「物件陣列動手實作：病患用藥清單資料結構設計」段落，實作時段：65-95分鐘

## 學習目標

練習用「物件陣列」表示多筆結構化資料，並寫出能走訪陣列、依條件篩選物件屬性的程式碼。

## 操作步驟

1. 四人一組，先在紙上討論：如果要記錄多位病患的「姓名、年齡、目前用藥種類數」，應該用什麼樣的資料結構最合適？畫出你們的設計草圖。
2. 將設計草圖轉成提示，請AI生成一個物件陣列（每個物件代表一位病患）以及一個函式，篩選出用藥種類數大於等於3的「多重用藥」病患名單。
3. 對照下方「測試資料」表格，手動列出你預期會被篩選出來的病患姓名，再執行程式碼比對實際輸出。
4. 修改資料，加入一位邊界情況病患（用藥種類數剛好等於3），確認程式碼的篩選條件是否正確處理邊界值（>= 3，而非 > 3）。
5. 組內輪流口頭解釋：為什麼用物件陣列而不是四個各自獨立的陣列（姓名陣列、年齡陣列……）來儲存這些資料？

## 給AI的提示詞範例（starterPrompt）

> 請用JavaScript寫一個病患物件陣列patients，每個物件包含name（姓名）、age（年齡）、medicationCount（目前用藥種類數）三個屬性，並寫一個函式findPolypharmacy(patients)，使用filter方法篩選出medicationCount大於等於3的病患，回傳這些病患的姓名陣列。

## 測試資料

| 病患 | 用藥種類數 | 是否應被篩選（>=3） |
| --- | --- | --- |
| 王小明 | 5 | 是 |
| 陳美玲 | 2 | 否 |
| 李大同 | 3 | 是（邊界值） |
| 張淑芬 | 1 | 否 |

## 提示（卡關時再看，上課前請勿提前公布）

- 物件陣列中的每個物件都用相同的屬性名稱（name、age、medicationCount），這樣才能用同一套邏輯走訪整個陣列。
- filter方法不會修改原本的陣列，而是回傳一個新陣列，只包含符合條件的元素——這與for迴圈搭配if判斷後手動push進新陣列的效果相同，但寫法更簡潔。
- 篩選條件要特別留意「大於等於」（>=）與「大於」（>）的差異，這會直接影響邊界病患（用藥種類數剛好等於3）是否被納入名單。
