# 獨立解釋checklist練習：準備回答教師的三個追問

> 第11週：實作工作坊①：CRUD強化與前後端串接練習 — 對應簡報「獨立解釋checklist練習：準備回答教師的三個追問」段落，實作時段：95-135分鐘

## 學習目標

在巡迴指導等待期間，學生兩兩一組互相練習「獨立解釋checklist」，事先準備好回答教師可能提出的三個追問（這段程式碼在做什麼/為什麼這樣寫/可能的風險），確保被巡迴到時能真正展現理解而非臨場緊張說不出來。

## 操作步驟

1. 從自己第9-10週或本週完成的CRUD程式碼中，任選一段自己覺得「還不是很確定為什麼要這樣寫」的片段。
2. 針對這段程式碼，自己先寫下三個追問的答案草稿：這段在做什麼、為什麼這樣寫、可能的風險是什麼。
3. 找組內另一位同學，互相扮演「教師」與「學生」，被問到的人現場口頭回答三個追問，問的人可以追加「那如果不這樣寫會怎樣」等延伸問題。
4. 互換角色，重複一次練習，並記錄下自己原本答不出來、練習後才想清楚的部分。
5. 教師或助教巡迴到本組時，優先詢問這段「自己覺得還不確定」的程式碼，作為正式的獨立解釋確認。

## 提示（卡關時再看，上課前請勿提前公布）

- 如果答不出「為什麼這樣寫」，可以先問自己「如果改成另一種寫法，結果會不會不一樣」，往往能幫助釐清設計選擇的理由。
- 「可能的風險」不需要講得很技術，用生活化比喻說明也可以，例如「如果劑量沒轉成數字，之後計算病人一天吃了多少藥可能會算錯」。
- 練習時建議誠實承認「這裡我還不確定」，比硬掰一個聽起來合理但自己也不理解的答案更有學習價值。

## 討論問題

- 練習前後，你對自己選的那段程式碼理解程度有什麼變化？
- 同儕互相扮演教師提問，跟直接被教師巡迴問到，感覺上有什麼不同？哪一種比較容易讓你誠實承認不確定？
- 這個checklist練習，如果換成是「請AI幫我解釋這段程式碼」，跟你自己想清楚再說出來，兩者對你的學習效果有什麼差異？


> 本練習為討論／口頭／書面型活動，無需程式起始檔。請直接參考上方操作步驟與測試資料於課堂進行。
