# 錯誤診斷練習：三段常見錯誤前後端程式碼片段

> 第11週：實作工作坊①：CRUD強化與前後端串接練習 — 對應簡報「錯誤診斷練習：三段常見錯誤前後端程式碼片段」段落，實作時段：35-80分鐘

## 學習目標

運用本週學到的四類常見錯誤分類（欄位命名不一致、資料型態不符、非同步時序問題、缺少錯誤處理），分組診斷並修正三段刻意植入錯誤的前後端串接程式碼片段，延續用藥提醒系統或自己的期末專案schema。

## 操作步驟

1. 分組後，每組領取三段codeBuggy程式碼片段（可延續下方testData欄位提供的三個片段，或改用自己專案中卡關的實際程式碼）。
2. 針對每一段，先不要急著修改，而是先用口頭或紙筆寫下「我猜這裡的錯誤類型是什麼」（四選一：欄位命名/資料型態/非同步時序/缺少錯誤處理）。
3. 用console.log或typeof等診斷技巧驗證猜測是否正確，記錄實際驗證過程。
4. 確認錯誤原因後，動手修正程式碼，並整理成codeGood版本。
5. 教師或助教巡迴到本組時，任選一段程式碼，向教師口頭說明錯誤原因與修正邏輯，準備好回答三個追問。

## 測試資料

| 片段 | 程式碼情境 | 植入的錯誤類型 |

## 提示（卡關時再看，上課前請勿提前公布）

- 遇到「資料不見了」先檢查console.log(req.body)或console.log(表單資料)，確認欄位名稱是否真的一致。
- 遇到「排序或比較結果怪異」，先用typeof檢查變數實際型態，很可能是字串被當成字串比較而非數字或日期比較。
- 遇到「畫面沒有即時更新」，檢查是否所有非同步操作都正確使用了await，或是否在.then()裡才執行後續動作。
