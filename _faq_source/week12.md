### Q1：點擊「在 Replit 開啟」之後，畫面跳出登入或授權要求，我是不是沒有被邀請就不能匯入？

不會。本課程的教材倉庫 `course-materials-vibe-coding` 是一個**公開（Public）**的 GitHub 倉庫，任何人都可以直接讀取與匯入，**不需要老師事先加入你為合作者，也不需要額外申請權限**。

如果 Replit 要求你登入，那是在請你用「你自己的 Replit 帳號」登入（這樣匯入的專案才會存到你自己的帳號下），跟能不能存取老師的倉庫是兩件事。只要照平常方式用 Google 或 Email 登入 Replit 即可，跟 GitHub 授權無關。

### Q2：匯入完成後，Replit 裡出現一整個課程的資料夾，我要打開哪一個才是本週的練習？

「在 Replit 開啟」按鈕會把**整個學期的教材倉庫**一次性匯入（因為所有週次共用同一個倉庫），所以匯入完成後，請在檔案總管裡找到本週對應的資料夾：

```
week12-auth-security-basics/
```

打開這個資料夾即可看到本週的練習檔案（`exercise` 開頭的子資料夾、`README.md` 練習說明等）。如果只看到倉庫根目錄的 `README.md`，代表你還沒有點進正確的週次資料夾。

### Q3：我在資料夾裡找不到 `solution.*`（解答檔），是不是匯入失敗了？

不是匯入失敗。教材倉庫重新整理後，公開倉庫（也就是你匯入 Replit 的這個倉庫）**刻意不包含任何 `solution.*` 解答檔或參考答案 SQL 檔**，目的是讓同學先靠自己動手嘗試、除錯、與 AI 協作討論，而不是一開始就看到答案。

參考解答統一保存在老師另外維護的私有倉庫中，**老師會在課堂講解或作業回饋時另外公佈或釋出對應週次的解答**，請留意課程公告或直接於課堂詢問老師，不需要自己在公開倉庫裡尋找解答檔案。

### Q4：匯入之後執行程式出現錯誤（例如找不到套件、權限不足、無法執行），怎麼辦？

可以先確認以下幾點：

1. **確認你打開的是本週資料夾**（見 Q2），而不是倉庫根目錄——不同週次可能會用到不同的檔案與執行方式。
2. 依照本週練習 `README.md` 裡列出的安裝或執行指令，重新在 Replit 的 Shell（終端機）視窗中執行一次。
3. 若錯誤訊息提到套件（package/module）找不到，通常表示相依套件還沒安裝完成，可稍等 Replit 自動安裝，或依照 README 指示手動安裝。
4. 仍無法排除時，把完整錯誤訊息複製下來，貼給 AI 協作工具（例如 ChatGPT、Claude、Replit AI）詢問，或於課堂／課程討論區提出，附上你已經嘗試過的排解步驟，會更快得到協助。

### Q5：除了用「在 Replit 開啟」按鈕，還有其他方式可以取得本週練習檔案嗎？

可以。因為倉庫是公開的，你也可以用以下任一方式取得完全相同的檔案：

- **直接下載 ZIP**：到[課程教材倉庫](https://github.com/cclhlee/course-materials-vibe-coding)頁面，點選綠色「Code」按鈕，再選「Download ZIP」。
- **使用 `git clone`**（若你的電腦已安裝 Git）：
  ```
  git clone https://github.com/cclhlee/course-materials-vibe-coding.git
  ```
- **使用 GitHub Desktop 或 VS Code 的「Clone Repository」功能**，貼上上面的倉庫網址即可。

以上方式都不需要任何授權設定，因為倉庫本身就是公開可讀取的。

### Q6：我該如何提交本週作業？

請依照本週頁面「練習區」或課程公告中說明的提交方式進行回傳，若不確定，請直接詢問老師或參考當週的作業說明文件。
